# HR Open Standards — Reference Schemas

This directory contains a **reference copy** of selected [HR Open Standards]
(http://www.hropenstandards.org) v4.2.0 JSON schemas that the Cybergy Talent
data model maps onto (the `PersonProfileType` and its dependencies).

These files are included for developer convenience and traceability only. The
Pydantic models in `backend/app/schemas/hr_open_standards.py` are a Python
mapping of these schemas.
